# 作者作品中的每日发布查看

用户日常验收包括：每日粉丝及变化、每条作品点赞及变化、主页总获赞及变化、每天是否发布及发布条数。作品存量变化不是发布数量。

本次在现有“全部作者 → 全部已保存作品”弹窗内增加北京日期选择和当天作品筛选，不新增业务页面、不区分表格板块。统计直接使用同一作者已经合并、按作品 ID 去重的记录；标题、点赞、排序、搜索、分页和 CSV 均沿用该作品集合。

- 已保存至少一条当天作品：显示“已有发布记录 · 至少 N 条”。不把已有数量冒称全部。
- 没有当天记录：显示“发布情况待确认”；无法从有限列表证明未发布。
- 没有可靠发布日期的作品：保留在全部日期，说明其数量；不按导入日或采样日安排发布。
- 迟于版本截止时间的精确发布时间、迟于截止日的日精度记录：不算入当前发布计数。
- 日精度来源保持日期精度；平台时间按北京时间归日。版本固定，今天仍标明未结束。
- 同作品重复记录只计一次；日期冲突或作品身份无效则停止计算，不悄悄选一个日期。

计算模块 `lib/author-daily-publication.mjs`；展示 `components/author-daily-publishing.tsx`；接入 `components/author-unified-works.tsx`。日选择只筛选当前已读取作品，不触发平台请求、模型调用或新采集任务。

新增 8 项计算及实际组件静态渲染回归，完整 343 项普通前端测试、类型检查和生产构建通过。固定真实发布版本逐文件核对摘要后，与独立北京时间计算对照；业务数据和明细证据留在资料持有者本机。

当前计算和页面呈现修复不代表采集恢复。单条公开视频只读 HTTP 试验得到 HTTP 200 的页面外壳但没有匹配作品，不产生有效点赞或发布时间观测，没有接入批量采样。未启动浏览器；本轮没有实际点击、手机端或真实用户使用测试。
