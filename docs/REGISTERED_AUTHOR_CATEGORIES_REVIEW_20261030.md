# 原表登记类别发布与作者筛选修复

## 问题与结果

后台已经按原表的明确登记字段识别切片、原创、AI二创作者，但发布作者分区只保留了作品计数等字段，丢失 registeredClassifications。前端又只看类别作品数或监控标签，因此有登记类别、尚未收录该类作品的作者会被分类筛掉。

本轮接通现有统一数据链路，不另建业务板块：
- 发布端只追加白名单类别，不发布登记记录、联系方式、授权、奖金或原表附件。
- 严格分区校验支持旧作者结构和含登记类别的新结构；拒绝未知类别、重复类别和额外私有字段。
- 统一作者名册和来源作者列表按“登记类别或已有作品类别或监控标签”筛选，并展示登记类别。
- 两处作者CSV在末尾补充登记类别，保留原有指标列位置。
- 登记类别不增加作品数、不替代作品本身的类别、不代表启用监控或取得新样本；未分类作者也不再误收已有明确登记类别的人。
