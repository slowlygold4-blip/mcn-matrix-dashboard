# 采集链路当前状态

审查基线：2026-11-04。本文件记录本轮接入新传输通道前已核验的运行边界；同日开发中的补丁不因此被视为已上线或已获得真实采集覆盖。发布状态须另有部署记录、运行回执和公开数据回读。

## 已有链路与实际缺口

| 环节 | 已有能力 | 不能据此认定的结果 |
| --- | --- | --- |
| 主页统计 | 普通脚本调度、读取、留存粉丝及总获赞快照，记录失败和采样时间 | 主页成功不等于作品列表成功，也不等于逐作品点赞更新 |
| 来源表格 | 导入、身份关联、作品去重和历史事实入库；与采集观测使用统一作者和作品索引 | 刷新来源表时间不能冒充每条指标采样时间；提交时间不能自动当发布时间 |
| 抖音自动作品采集 | 现有匿名 HTTP 作品列表尝试和失败记录；本机浏览器补采已停用 | 本轮核验仍有真实 HTTP 403；持续完整的逐作品点赞和每日新发布库存尚未证明恢复 |
| B 站已登记作品 | HTTP 通道可更新已登记作品的指标并保留观测 | 已知作品更新不等于完整枚举作者新投稿，不能据此确认每日发布总数 |
| 远程作品回执入库 | 校验身份、作品、时间与分页证据后进入现有作品和指标表 | 接受回执的工具不是抓取器，更不代表自动调度已接入 |
| 导出与前端 | 读取真实落库数据，计算可比变化，保留缺测和覆盖信息 | 页面正常、导出成功或测试通过，均不代表平台数据全量采集成功 |

采集、排队、去重、入库、计算和发布由普通脚本运行，不调用语言模型。开发、代码审查和对话本身不属于这项运行时保证。单机脚本不能在电脑关机或离线时继续向平台请求，也不得事后伪造离线期间的采样。

## 人工远程样本不是自动采集

已核验的两次远程作者作品列表样本由人工执行取得，并经过身份校验写入现有主库。它们证明有限的真实观测和入库路径可行；没有证明无人值守调度、全作者运行或完整分页。对旧回执重放可以检验兼容性与幂等性，不能算作新采样。

现有 [`admit-remote-work-page.mjs`](../scripts/admit-remote-work-page.mjs) 只接收操作者提供的回执，默认预检；明确提交后才入库。它不发网络请求、不启用采集服务，输出 `automaticCollectionEnabled: false`。核验与落库由 [`remote-work-observation.mjs`](../lib/remote-work-observation.mjs) 完成，覆盖读取见 [`remote-work-coverage.mjs`](../lib/remote-work-coverage.mjs)。新自动通道必须有独立、可验证的执行状态，不能把这个人工工具套进循环后仍沿用人工执行标记。

旧回执缺少游客回退标记时，状态是未知，不能推断为 `false`。HTTP 200、返回作品或 `has_more: false` 均不足以单独证明列表完整；需要保留实际观测时间、作者身份、游客回退状态、游标以及分页范围。有限列表不得报成当天全部作品。

## 外部演示服务的用途

公开 demo 可以用于有边界的接口评估；公开源码和可调用接口不等于长期生产服务保障。已查看的上游项目将演示实例定位为自部署前的评估资源，不应直接作为无限期监控依赖。限流阈值也不是可承诺的生产容量。参考[上游固定版本说明](https://github.com/Evil0ctal/Douyin_TikTok_Download_API/tree/5aa03528d2e974a0de23faf86597b5af3420df55)。

有限评估的成功结果只能作为其真实身份、时间和范围内的观测。登录要求、403、429、超时或服务故障须记录实际原因；不能换身份、代理或浏览器绕过拒绝，也不能删掉冷却状态或把延后任务改成成功。共享传输冷却不表示每个待处理账号都独立收到平台封禁。

## 新通道上线前的验收

本轮新增传输与调度接线仍需独立验证，至少满足：

1. 默认关闭；显式配置合法服务、认证方式、目标范围与有限评估截止时间。不得隐式扩名单、延长评估或读取本机抖音登录态。
2. 由普通脚本自动发起请求，留存独立执行回执和持久状态；并发互斥、取消、超时、重启恢复、失败退避与幂等入库都有可重复测试。
3. 校验平台、精确作者及作品身份；沿用统一作品索引，保留真实采样时间、来源和分页证据。旧人工回执保持可读、可回放，不改写历史。
4. 分别验证主页统计、已观测作品、完整作品列表覆盖；单作品日点赞按北京时间相邻日有效采样相减，缺测不填零、减少不抹除。
5. 每日发布数量依据明确发布时间并去重。部分库存显示“已发现/至少”，覆盖未确认时不能报“未发布/0 条”；作品存量变化不能代替发片数。
6. 先通过 [GitHub 云端 QA](https://github.com/slowlygold4-blip/mcn-matrix-dashboard/actions/workflows/product-collection-ui-qa.yml)，再核验获准范围内真实自动请求、数据库追加及发布后回读。合成测试通过、人工提交成功和真实自动运行分别记录。

日常四项指标的完整规则见 [DAILY_MONITORING_ACCEPTANCE.md](DAILY_MONITORING_ACCEPTANCE.md)。本文件不包含业务名单、私有回执、凭据或原始业务资料，也不宣称上述上线验收已全部完成。
