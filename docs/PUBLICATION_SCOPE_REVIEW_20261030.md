# 作品台账范围与聚合审查 · 2026-10-30

## 问题与修复

主页面的矩阵、大主题、作者分类过滤的是账号；旧版ContinuousPublishing没有收到这些值，始终使用团团固定台账。旧导出同时忽略已通过账号历史审核但不属于团团来源库的作品。切换范围时，用户会看到不对应的作品数量和指标；这属于产品数据范围错误。

统一导出现在合并原团团作品模型与全部账号已审核的作品历史。原有作品ID只保留一个已采用值，不把不同来源相加；新增作品保持已保存字段来源。身份冲突只留在原账号历史供核验，不任意分配给某作者。源表仍参与同一个作品模型，不新增独立数据产品。

- 抖音按抖音作品ID，B站按BV号；内部去重使用平台+作品ID，链接也按平台生成。
- 按当前已持久化主题、板块、作者标签建立互斥范围桶；同一作者属于多个板块或标签不会重复计数。仅有登记数据的团团作者，沿用用户确认的团团切片矩阵归属，补充明确报名标签；不从昵称或作品标签猜作者分类。
- 作品明确话题标签是第二层过滤，不等同作者内容分类。
- 默认矩阵范围排除独立主播，明确选择主播板块/主题才统计主播作品。停用账号的已保存作品历史保留；作品库统计不是启用主页样本数量。
- 账号范围、发布日、作品标签共同作用于卡片、日历和明细。切换范围复用已核验的当天分区，不重新请求平台，也不再读全量作品。
- 旧数据索引可读；旧版未包含其他范围时明确提示等待数据同步，不用团团数字冒充其他主题。

## 数据与语义

来源观测、主页日快照、作品累计指标仍保留各自采样/时间含义。发布日期只用于发布记录分组，不能当成当天点赞/播放增量；new_issue也不能代替逐作品发布记录。缺日留空，缺指标为null，真实来源明确的0保留；抖音公开播放占位0不升级为实测0。

本次只读核验已确认发布的2026-10-29T20:03:11.634Z：4263个保存分区完成字节/SHA核验；旧57770条记录的日期和已采用指标变化0。新台账61385条，额外纳入3615条已有记录，其中全台账抖音61108条、B站277条；不是本轮新采集。默认矩阵59782条，团团59377条，独立主播1603条；不同范围不能互相替代，也不能称平台全覆盖。分类桶50个。详live-catalog-proof.json，生产新一代会随真实采样继续变化。

范围桶按日保留合计并用别名复用完全相同的作品标签合计，减少重复指标对象；该固定快照索引约889KB，未压缩版本，不把这个数字当网络性能实测。
