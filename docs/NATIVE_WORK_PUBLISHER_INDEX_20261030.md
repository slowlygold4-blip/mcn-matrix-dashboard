# 原生作品发布者索引与统一日常监控

## 验收口径

延续[日常监控标准](DAILY_MONITORING_STANDARD_20261030.md)：粉丝及日净变化、每条作品的点赞及日净变化、主页总获赞及日净变化、每日实际发布情况。账号总获赞不等于已收录作品点赞之和；存量作品数净变化不等于当日发布条数。缺采样不补零，列表不完整时不能判定当天没有发布。

## 本次修复

已知监控账号的作品，不再必须先绑定某个表内作者才能进入统一作品索引。只处理原始或补充来源已有的精确作品ID交集；校验原生作品ID、原生作者sec_uid、已有账号canonical锚点、平台、观测和发布时间。多发布者冲突、身份或时间矛盾拒绝采用。未导入与来源无交集的其他账号库存，不按昵称猜身份，不改变账号启停、主题、登记分类或原始作者声明。本轮5条中4条属于团团既有账号，另1条的实际发布账号原属独立主播范围，仍在原范围的账号详情查看，不能为凑矩阵计数而把主播加入团团名册。

实际发布账号以已有账号实体进入经营查询、作者合计、作品详情与每日发布台账；没有伪造作者身份关联。原总表与补充来源沿用各自不可变的版本和行索引，公开归属证明仍须对应同代际唯一原生作品分区。

可选sourceClaimMatches只接受显式true，表示来源公开抖音号与已核验作品发布者的公开抖音号一致，允许保留该作品已提供的累计值。它不建立来源作者身份关联。未关联的来源声明保留可查，但不在另一个作者节点下重复贡献；原生账号仍仅计算一次。该值缺省时保持原来的冲突规则。

## 性能与一致性

候选账号先按作品ID取得唯一target_id，再读取账号元数据，避免对大量作品重复去重整段元数据。账号详情采用按target分组的归属索引，只在所属同步只读快照作用域中复用；换来源、换截止时间、同连接写入或结束作用域后均重新核验，返回数据使用独立副本。首轮发布准备暴露出每个账号重复全量扫描的问题，该未封存准备被停止后修复，未将旧公开数据覆盖为半成品。

真实库只读核对：作品集合及数量保持79,961条，5条归属更新涉及3个已有账号，原表、作者绑定、历史和账号设置不改。独立原始ID/作者/锚点复核通过。1,000个账号详情读取约2.6秒；第一次约2.4秒建立索引，后续查询未重跑全量原生扫描。以上是本次机器与固定历史截止的观测，不是跨设备性能保证。

208项相关后端测试、362项前端测试、前端类型检查和生产构建通过；覆盖无来源作者绑定、缺公开抖音号、原声明保留、两个来源命名空间、作者/作品/日期统计一致性、缓存失效、历史截止、空值与旧发布版本兼容。

## 未完成的硬指标

归属和呈现修复不是新增平台采样。最近公开采样状态中，抖音当日作品点赞观测仍为0，不能宣称全量每日单作品变化已采齐。完整作品列表、所有作者身份接通、稳定授权通道仍有真实缺口。继续保留缺测原因；不使用本机抖音浏览器，不绕过访问控制，不把测试通过说成采集覆盖通过，也不称已完成实际浏览器或真实用户验收。
