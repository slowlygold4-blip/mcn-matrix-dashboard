## 修复的问题

1. **批次结束时间覆盖单作品读取时间。** B站脚本依次请求作品详情，原先将所有作品指标写在整个账号批次的结束时刻。跨北京时间零点时，零点前读到的点赞会被划到后一天。现在每条详情保留响应读取时间，列表降级字段保留列表读取时间；数据库复核归属、原始校验和、时间范围及标准化结果后，使用逐作品时间入库。发布日期不参与指标时间判断。
2. **详情缺少作品 ID 回显核对。** 旧代码只核对作者 UID，同一作者另一条作品的返回数据可能被记到请求作品上。现在要求返回 BVID 与请求完全一致且作者 UID 一致；不一致不采用指标。
3. **重复列表引用导致重复详情请求。** 同批相同 BVID 只请求一次。未新增端点、请求类型、重试、并发、调度器或模型调用。列表降级仍没有点赞值，保持 null。

新增的 `bilibili-work-observation.mjs` 只处理现有采集器的时钟回执。原始记录没有该回执时保留旧行为，不回写历史；已声明但不合法的回执不能静默降级。原表、历史、分类和启停设置不变。不修改前端，公开站仍为 v138。
