# 原有来源循环自动补齐作品引用

原作品补链命令可用，但一次性CLI不会处理以后新登记的短链。本次把数据任务移入 `lib/work-source-link-batch.mjs`，命令行仅解析参数、验证备份并调用同一模块；`createWorkSourcePollReader` 也直接调用模块，不通过子进程串联采集脚本。

## 已接入的路径

已有每日来源流程：核对工作簿版本 → 必要时导出/事务追加原事实 → 检查该版本待关联短链 → 匿名普通HTTP解析 → 追加精确来源回执 → 统一作品投影/缓存/发布变化检测。即使原表版本不变，先前未处理的引用也能继续处理。解析出ID不等于得到作者归属、指标观测时间或发布日期。

仅对已审查的来源显式启用 `resolveWorkLinks: true`。原目录只修改发布登记作品来源，其他20条登记策略及账号身份/启用/分类保持原样。默认每批50个去重链接，允许1–100个；间隔700ms，允许500–10,000ms。已关联URL不再请求；同一作品仍只算一次。

未处理的新引用通过原source-poller的现有循环在5分钟后接续，不另建任何定时器或进程；分批操作不刷新“整日来源检查完成”标记，完整每日检查始终优先。401/403/429会停止当前批并令整个匿名短链路径冷却24小时，不能换另一个URL继续规避拒绝；网络错误/超时停止并冷却5分钟。普通不可识别跳转保留24小时重查时间，连续5个无可用结果停止当批。

## 并发、留存与资源

CLI和来源进程共享文件租约；写完JSON后原子呈现，任何其他活动租约都使本批暂缓。崩溃进程的租约不会阻止新进程，也不删除他人的租约文件；仍兼容旧CLI的活动固定锁。一个来源进程、现有调度、无浏览器、无签名/验证码/新供应商、不读登录Cookie、不调用模型。

只有有待处理网络任务时才验证备份并打开写库；整本导入与补链同一来源批次复用一个备份门禁。无待处理项时0抖音请求、0回执新增、0备份重验。活跃一致性备份期间让出写入；原件、行事实、计数及日期不修改。

`data/source-poll/work-links/<UUID>/` 保存每批规划、结果和原回执；0600/0700私有权限。来源清单和状态接口仅显示计划/已处理/已解析/失败/剩余/未关联/冷却数量、下一检查时间与固定错误码，不带URL、Cookie或任意异常原文。未关联数并非待采账号数，补链成功数并非单作品每日点赞采样数。

## 验证范围

17个相关测试文件144项通过，包含复用备份、空任务不发请求、去重后分批接续、403路径级冷却、互斥与死进程租约、取消/备份门禁、原策略兼容、来源合同切换、部分检查不提升每日完成、到期任务沿用既有循环、完整每日检查优先、公开状态脱敏及真实0/日期/合并规则。均不把合成HTTP响应当作真实全账号采样成功。

本功能自动处理来源作品引用；它没有恢复平台每日单作品点赞或完整发布列表。粉丝与主页获赞、逐作品点赞及每日发布仍需分别以真实采样覆盖验收。当前首次生产接续及公开回读以维护日志为准，不能仅因代码合并就称已在运行。

## 正式接续结果

原受管来源进程已完成一次真实自动巡检：工作簿版本不变，已关联URL全部跳过；0个计划请求、0个抖音请求、0条新增链接回执、0次备份重验。剩余1个回首页的链接保持真实冷却时间，未被标为已关联；原工作簿readAt与每日完整检查时间不变，其他20条来源策略未改。状态HTTP已返回单独计数和warning。

23:28公开截面的creator/index和作品末分区匿名GET200，字节/SHA一致，405个关联作品在公开分区可见。但公开导出未保留切片分类字段，公开切片筛选尚未通过验收；不能拿后台HTTP筛选通过代替。

当前作品失败记录主要为transport-cooldown，另有blocked/login_required。审查确认跳过冷却请求时直接返回既有decision，不再record失败，到期时间不会被每个跳过账号续期。本次未重置、缩短拒绝冷却或更换身份请求；单作品日常采样仍未恢复。
