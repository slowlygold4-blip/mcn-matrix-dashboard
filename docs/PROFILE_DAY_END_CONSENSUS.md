# 粉丝、总获赞与作品存量的日末观测

同一个账号在同一实际时刻有两个不同粉丝值时，不能用较大的数据库行号决定增长。例如昨天100、今天同刻110与120，不应报成增长20。

账号历史、经营总览、日曲线、共同已观察时段和当天覆盖使用同一个指标选择器：

- 每项指标独立选择当日最后有效观测，保留真实零值和下降。
- 同时刻不同值形成冲突；该时刻的值与增减为缺测，不能用更早数据掩盖。
- 晚于冲突的缺字段记录不能解除冲突；更晚的真实指标观测可以解除。
- 前一日末值冲突时，下一日不计算日变化，也不把它当作共同对比基线。
- 同一时刻数值相同的重复凭据不制造冲突；互补的部分指标各自保留对应来源指纹。
- 旧基线查询保留同刻全部候选凭据，避免查询阶段先丢掉矛盾的一条。

这是只读计算修复，不删除或改写任何原始观测。公开日分区仍使用原JSON结构，冲突指标、时刻、来源指纹及其变化均为空，其他有效指标继续显示。

本轮相关测试包含真实内存数据库、账号与矩阵API读模型、趋势、补充对比及公开导出；不会将测试通过描述为作品采集权限已恢复。
