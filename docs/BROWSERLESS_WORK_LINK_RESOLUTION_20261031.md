# 无浏览器的登记作品短链接关联

依据：[MediaCrawler resolve_short_url](https://github.com/NanmiCoder/MediaCrawler/blob/68d9ef1c1da22eab75940dfd7cec259907006538/media_platform/douyin/client.py#L372)使用单次HTTP GET读取302 Location；[bilix](https://github.com/HFrost0/bilix/blob/bb5b234cdfe3fafc4db9d992b91091f2edf791e5/bilix/sites/douyin/api.py#L37)也先展开短链，但后续旧iteminfo接口已在本项目实测空响应，不能因此认为作品点赞可采。本实现没有复制或执行第三方采集器，没有调用旧空接口。

## 做什么

`lib/work-source-link-receipts.mjs` 对已入库的官方短链接执行一次普通匿名GET，使用明确的程序User-Agent，不读Cookie，不生成签名，不跟重定向，不下载HTML或视频。只接受官方HTTPS域名直接作品路径中的唯一ID。查询参数不作为新权限或签名使用，也不留在跳转回执URL中；原Location仅留SHA。403/401/429不换身份重试。

回执作为独立不可变证据追加SQLite，不改写原始表格事实或原生采样。提交要求最近一致性备份、精确来源版本及行哈希，历史查询只采用截止前已提交的回执。重复作品仍只算一次，链接冲突不按先后或多数选ID；不推断作者归属、发布时间或指标观测时间。缺日不补零，计数真0保留。

统一作品库与其缓存、公网发布变化检测接入已准入成功回执；失败回执用于24小时冷却，不凭失败重建整份公开数据。原件、行、版本与链接回执一并属于备份证据表目录。

## 普通脚本运行

先只读规划（不请求抖音、不写业务数据库，报告目录必须新建）：

```sh
node scripts/resolve-work-source-links.mjs --database /absolute/data/douyin-monitor.sqlite \
  --version-id 5 --report-directory /absolute/private/new-plan
```

实际执行需增加 `--execute --backup-path /absolute/recent-backup.sqlite`，并使用新的报告目录。默认一次最多500个去重链接，串行、间隔700ms；最短允许500ms。收到拒绝或网络/超时就停止，连续5个无可用结果也停止。单独的持久锁阻止第二个同类任务；已有锁不擅自删除。中断保留此前真实回执和结果，后续规划跳过已关联及24小时内失败链接。

检测到仍在运行的一致性备份时，任务在请求和入库前等待，不持有数据库写事务；等待有12分钟上限，支持取消，既有备份锁不删除。

运行不调用模型、不消耗模型token，无浏览器或验证码处理。当前是显式的一次性来源补链数据任务；未声称增加自动调度，未来来源日常同步依旧由已有来源worker执行。补链成功不代表作品指标已日常更新。

## 验证

71项相关单元/集成回归通过：官方域名、禁止自动跳转、身份/日期不猜测、指标0和累计去重、相反ID冲突、来源证明、备份门禁、截止时刻、回执及索引损坏、失败冷却、缓存与公开来源标记。最初新增表与旧测试预期不一致，统一建表入口及6表目录后全量相关测试重跑通过，没有降低备份验证要求。

真实任务的数量、成功率及统一HTTP核对以私有维护记录为准；不得用合成测试或单个302将全部作品采集标为成功。尤其单作品每日点赞和完整每日发布仍需真实新观测与列表覆盖证明。


## 本轮真实接入结果

461条原始短链接记录去重为410个请求。经两次有序、互不并发的数据任务处理，409个不同链接解析成功，1个真实跳回抖音首页，无法证明作品ID。460条来源行补齐作品引用，共405个来源作品ID（含原有直接ID），并入同一经营数据集。原始指标、原件和日期未改写。

来源层新增402个作品引用，其中大部分与已有平台作品重合；统一经营接口去重后的总作品实际从80,019变为80,049，只新增30条，不能宣称新增402条业务作品。既有作品ID全部保留，来源集合重复ID为0。

启动备份曾与持续入库争用SQLite，导致启动等待。已在采集空闲门禁维护加载Main，补链任务有序停止并保留375条尝试，再接续剩余35条；脚本随后加入主动避让备份逻辑。新33表一致性备份通过临时同inode硬链接只读quick_check与全表计数校验，无第二个3GB验证副本。首次任务的cancelled仍保留，不篡改为completed。
