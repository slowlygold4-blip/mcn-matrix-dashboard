# 账号每日发布查询审查 — 2026-10-30

账号历史此前主要显示每日作品存量变化，无法直接回答某天发布了哪些作品。现在账号历史和作者作品详情共用每日发布模型：进入账号历史 → 作品 → 选择发布日期 → 应用日期 → 仅看这一天的作品。现有排序、分页和 CSV 导出均使用同一过滤结果；从单作品点赞历史返回会保留日期和排序。

## 计算边界

- 按实际作品 ID 和北京时间发布日期去重。采样日、导入日和作品存量增减不参与发布计数。
- 账号模型验证每行账号归属及平台作品 ID；目前支持抖音和 Bilibili，未知平台明确拒绝。
- 已保存作品不代表全量作品：有记录显示“至少 N 条”，没有记录显示“发布情况待确认”，不能据此判定未发布。
- 日期不明和未来作品不归入当天。当天未结束时明确提示；缺失点赞基线不补零。
- 日期编辑通过原生表单应用，避免逐段修改日期时立即刷新结果。320px 下输入框保留完整日期宽度，按钮可换行。
