# 每日作品点赞变化的可用性核对

采到今天的点赞累计值，不等于能计算今天的日变化。本轮在原有分平台采集进度中补充三项：可计算相邻日变化的作品数、缺有效前日基线的作品数、当日末次观测冲突的作品数。没有新增业务板块或改变原有视觉样式。

## 规则与运行

按平台与精确作品ID去重，每个北京时间自然日取最后一次有效非负安全整数点赞。只有今天与昨天都有唯一有效末次值，才计为可计算日变化；0、下降也可比。不拿两天前的值冒充昨天基线。同一末次时刻的矛盾值不能任选最大值，也不能记为0。不同平台不混算，暂停账号、未来指标、未来首次发现的作品及不合法数字不进入覆盖。查询只读最近两个自然日数据；输出只有固定平台和覆盖计数，没有作品ID、原始指标、凭据或提供方文本。

数据通过原有collection-progress、relay、safeProgress进入原有进度面板。比较字段是可选、绑定原代际北京日期及平台分母的契约；旧服务或非法证明显示尚未上报，不伪造成0可比。未改变调度频率、采集入口或建立新后台任务；运行时不调用模型。

## 真实复算与测试

在固定时刻的真实数据库只读事务中，新旧观测计数完全一致，并与不调用新生产函数的独立参考算法比对通过。具体业务覆盖计数和查询耗时留存在资料持有者的私有维护记录；测试不是采集成功率证明。

后端相关20项、前端352项、类型与生产构建通过。新组件实际静态渲染、relay白名单和跨平台日期/分母/隐私测试通过。一次TypeScript缺失可选字段类型已修正；本地晋升首试使用错误工作目录，在写入前失败，改成绝对路径并核对原件SHA后晋升，正式目录20项复验通过。未做实际浏览器点击或移动端验收。公开发布和服务加载证据另见维护日志，不以代码测试代替线上结果。
