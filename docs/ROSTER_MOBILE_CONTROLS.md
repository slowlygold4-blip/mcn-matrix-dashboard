# 作者名册的手机筛选与分页

手机默认常显搜索、当前范围和排序摘要，范围按钮与两个排序选择框在“筛选与排序”中展开。桌面继续直接展示完整控件。收起只是显示状态，不改变URL、筛选条件、排名或导出范围。

跳页仍先输入、提交才导航；上一页、页码与下一页在窄屏同排，错误页码明确提示。统计说明仍可展开，缺少的指标继续显示缺测。作者、指标计算及来源关联未改动。

实现复用现有 `useIsMobile`，样式集中在 `frontend/components/tuantuan-roster-controls.css`，不改变其他来源表控件。`TuantuanRosterTable` 保持原有地址恢复、表头双向排序、筛选后回到第一页、全匹配CSV导出及来源原登记标识检索。

验证包括：

- 403项前端非浏览器回归及TypeScript检查通过。
- 3份真实组件浏览器测试、13项用例通过，均使用合成数据并拦截全部外部请求；涵盖手机收起/展开、键盘焦点、排序范围摘要、别名搜索导出、页码草稿/校验、屏幕宽度切换和既有导航生命周期。
- 本机只读预览对真实已公开名册执行17步任务：原登记号查询、启用范围、粉丝排名、键盘收起、跳到最后一页、导出当前全部匹配。最后一页显示第165/165页的8位作者，CSV包含全部4928位作者，不只导出当前页。该观察不代表真实用户留存试验。
- 实际390px页面首位作者相对名册顶部由约865px降到568px；320px由约1202px降到632px，均无页面横向溢出。这是当时数据和相同视口下的测量，不承诺所有内容长度都相同。

这些交互改善不代表逐作品日采恢复。采样覆盖、数据时间与缺口继续单独展示。
