# 作品采集的响应契约

作品请求失败不能覆盖历史作品，也不能生成“当天未发布”或零点赞记录。主页粉丝、主页总获赞与作品指标分别验收。

本次修复的具体情况：

- `status_code: 0` 同时包含明确登录/验证要求时，即使返回终止空数组，也不是完整的零作品观测。
- 受审查的主页、作品列表和详情请求在 HTTP 跳转时停止；不跟随跳转目标。作品列表还校验最终 HTTPS 主机和接口路径。
- 传输在响应结束前中断，但已经取得401、403或429时，保留该拒绝原因，不改成较短等待的普通网络错误。
- 没有明确登录要求的公开作品窗口 `not_login_module` 仍可保留为有限样本；缺字段和真实零值继续区分。

已移除没有生产调用的旧 `signed_url` / X-Bogus 导入与路径注入，以及对应的部署前置要求。原第三方文件和许可证保留，没有改写历史来源或旧凭据。

验证包含：真实 Python 辅助脚本、假 HTTP 传输、合法/拒绝/跳转响应、归一化及临时内存数据库，验证拒绝后保留已有作品、点赞历史和可用主页指标。相关28个文件共334项测试通过；这是离线回归结果，不代表平台当前允许完整作品采集。

采集运行时不调用大模型，不新增浏览器、并行采集器或定时任务。完整每日作品点赞和发片验收仍必须以实际取得的作品数据为准。
