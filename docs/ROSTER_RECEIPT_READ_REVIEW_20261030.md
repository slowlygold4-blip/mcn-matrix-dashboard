## 本次修复

`master-roster-live-sources.mjs` 原先为每个最新来源任务读取并解析完整结果，即使所有行都有账号 ID、只需要严格身份凭据，也加载结果大字段。现在只有不含提交账号 ID、具有有效唯一主页定位的行才读取本任务结果；本次读取内按任务缓存一次。严格身份凭据、同来源证据、唯一当前目标及成功创建/复用回执的约束保留。非字符串定位值不能触发身份绑定或解析异常。

增加七组回归：无用大结果不读取、同任务共用、非法/歧义定位、缺失及失败结果、跨任务隔离、编辑后重新读取。补充 HTTP 测试原先向普通导入接口只提交预览行、没有原始文件，因此旧代码同样返回 400；改为提交真实 CSV 字节及其 SHA，继续断言普通导入不能伪造补充绑定上下文，没有放宽服务端校验。
